## 🚀 Latest — Ritrovato

> **Lost something in Rome? Describe it, say it or photograph it — in your language.**
> Built in **20 hours** at **Agentic Hack Rome** (Nov 2026).

Rome's lost-and-found registry exists only as ~500 pages/year of scanned Italian PDFs — no text, no search. **[Ritrovato](https://github.com/Honi05/Ritrovato)** OCRs the whole 2025–26 registry (**~15.7k entries**) and makes it searchable in seconds through an AI agent that turns natural language, voice or a photo into catalogue filters — in 5 languages.

- 🗣 **Text · Voice · Photo search** — ElevenLabs Agents + STT, DeepSeek fallback, keyword fallback when offline
- 📄 **Self-updating data** — daily OCR pipeline (Tesseract + PyMuPDF) ingests new city PDFs automatically
- 🏢 **Staff back-office** — photo-assisted item logging, inventory, and 15-min pickup booking
- 🎨 **My part:** frontend & design — mobile-first React UI in 5 languages

`React` `TypeScript` `Vite` `Tailwind` `FastAPI` `SQLite` `Tesseract` `ElevenLabs` `Docker` `Cloudflare Tunnel`
&nbsp;→ **[Live demo](https://ritrovato.quietunit.com)**
